IGBT Test Cell - virtual prototype (SIMULATION, offline). To launch: unzip the folder anywhere, then double-click index.html (or drag it into Google Chrome or Microsoft Edge). No install, no internet and no server are needed; everything runs from the local files via file://. selfcheck.html runs the built-in checks (validation, engine against the expected outcomes, reports) in the same browser. Tested browsers: Chrome or Edge (current versions). All readings are synthetic; no physical module is tested.
