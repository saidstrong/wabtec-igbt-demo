What happens next

  1. Configuration preflight checks every input. Invalid values stop here with no run and no verdict.
  2. Pre-check: interlocks IL1–IL7 must all read OK before START is enabled.
  3. Run: stages T00–T10 in order. The virtual bus is charged from T07. Any abort goes to the safe-state procedure.
  4. Result and report: overall outcome, safe-state status and per-reading evidence, exportable as JSON, HTML or PDF.

All rules are illustrative and not approved. Readings are synthetic.
